# A meta-methods review of methodological flexibility in the Iowa Gambling Task

## Overview

This project provides data and code to our study on methodological flexibility in the use of the Iowa Gambling Task. 

## Authors

Annika Külpmann, Jan-Paul Ries, Ian Hussey, Malte Elson.

## Folder Structure

**/code** is split into different folders with subprojects of our study and contains R scripts and thereby generated HTML files with the results of the meta-methods review, the multiverse analysis, as well as the sampling process and the inter-rater reliability. Each code draws on the corresponding folder in **/data**.

**/data/raw** contains the manually generated raw data of our study, broken down by subprojects. 

+ **/interrater reliability** contains the data generated by two raters, on the basis of which the interrater reliability was calculated. 
+ **/metamethods review** contains the data of the two raters combined into a master scoring for each of the codebooks, which was used to calculate the study results. I contains also two additional manually files, one with information regarding the study sample and one with scores that can be transformed into one another while preserving ranks.
+ **/multiverse** contains a dataset on which the multiverse analysis was based.
+ **/sampling** contains firstly a file with the population of articles used for our study and secondly a file in which this population was scrambled. From the file with the scrambled population, articles were drawn iteratively starting at the top to build the study sample. 

**/data/processed** contains data that were generated from the raw data by using the R scripts in /code and were needed for further analyses. 

**/meta-analyses** contains additional data used to provide context for our study which is presented in a part of the introduction but not in our own study results. 

**/methods** contains some files to make the procedure of our study transparent and reproducible. They are not needed to execute the code but can be used to understand what we did and how the data files were created in the first place. 

**/supplementary materials** contains pdf files with supplementary materials that we are enclosing with our preprint (coming soon!).

## How To Reproduce This Study

+ Start with the folder /code/sampling, here you can first scramble the population, this will reproduce the corresponding file in /data/sampling.
+ The second step would be to retrieve and code the articles, for this you could use the codebooks in /methods. However, if you only want to reproduce the code, skip this step. 
+ Next you can calculate the interrater reliability, for this you can use the code in /interrater reliability. There is one file for the IRR on procedure and one for scoring since these were two differently structured codebooks. 
+ You can then run the analyses of the meta-methods review. All the scripts are in the folder /code/metamethod review. There is no order that you need to follow for this step. 
+ Next up is the multiverse analysis, which builds partly on the code in meta-methods review. Run processing.Rmd first, then analyses.Rmd.
